# SafeZone Citizen

Accessible Next.js App Router shell for public Citizen information.

## Local commands

From the repository root:

- `corepack pnpm --filter @safezone/citizen dev`
- `corepack pnpm --filter @safezone/citizen build`
- `corepack pnpm --filter @safezone/citizen lint`
- `corepack pnpm --filter @safezone/citizen typecheck`
- `corepack pnpm --filter @safezone/frontend-tests test`

## Implemented boundary

The shell provides semantic landmarks, skip navigation, responsive public navigation, safe metadata and manifest, synthetic source/status demonstrations, and explicit degraded/offline presentation semantics. It performs no network requests and has no service worker or offline persistence.

## SDK-blocked follow-up

Generated SDK milestones are required before implementing live alerts, provenance history, verified shelters, authoritative freshness, service health, or API error states. This package contains no API client, DTO, endpoint, API-shaped fixture, map, IndexedDB storage, push notification, or submission behavior.
